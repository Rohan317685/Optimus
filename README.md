# Optimus 

This is a LED blinky sort of, it uses a capacitor for a hearbeat like effect where it dim's down after removing your finger from the two pin's.

I made this because it was unique and I was really curious on how electricty travelled through the human body.

I'm using a extra pair of 2 pin's where you basically keep your finger ontop of the 2 pin's and essentially your finger act's as a resistor and trigger;s the darlington pair transistors which let current through so it can light up the lighbulbs!

## Simulation

It work's using a Darlington pair which essentially amplifies the signal to the transistor's so when you keep your finger which is represented by the 10m resistor the current travel's through and trigger's the darlington pair 
which then make's the current flow through to the led's, when you take your finger of the capacitor releases excess energy which then create's a sort of dimming effect for a couple of second's!
